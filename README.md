# Área de Membros — Atlas Visual do Pizzaiolo

Página estática, mobile-first, com cinco materiais digitais.

## Abrir localmente

Abra `index.html` em um navegador moderno. Todos os PDFs ficam em `public/materiais/` e não dependem de caminhos absolutos do Windows.

## Estrutura

- `index.html`: página da área de membros;
- `styles.css`: identidade visual e responsividade;
- `script.js`: animação leve de entrada;
- `public/fonts/`: família Poppins;
- `public/materiais/`: cinco PDFs finais;
- `public/materiais/capas/`: miniaturas usadas nos cards.

O Atlas e o Manual de Pré-Preparo foram copiados sem edição. Os demais PDFs foram criados para esta área de membros.
